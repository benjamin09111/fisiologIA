# Glosario del dominio

| Término | Significado | En código |
|---|---|---|
| Curso / Módulo | Bloque temático del ramo (ej. Fisiología respiratoria, cardiovascular, renal, nerviosa). En el diseño se llaman "módulos". | `Course` |
| Unidad | División de un curso (ej. Unidad 1 · Mecánica ventilatoria). | `Unit` |
| Tema | Contenido dentro de una unidad. | `Topic` |
| Avance | % completado de curso/unidad/tema por el estudiante. | `progress` |
| Banco de preguntas | Conjunto de preguntas reutilizables, filtrables por curso/unidad/dificultad. | `Question` |
| Cuestionario | Conjunto de preguntas que el estudiante resuelve. | `Quiz` |
| Intento / Corrección | Resultado de resolver un cuestionario, con feedback por pregunta. | `Attempt` |
| Historial | Lista de intentos (del estudiante, o de todos los estudiantes para el docente). | `attempts` |
| Planificación | Calendario de estudio y evaluaciones. | `PlanningEvent` |
| Evaluación | Prueba programada (Solemne, Gynkana, etc.). | `Evaluation` |
| Solemne | Prueba formal del ramo. | `type: "solemne"` |
| FisioBot | Mascota/robot asistente. | `Mascot` |
| FisioIA | Asistente virtual (chat con IA). | ruta `/fisioia` |
| Paleta | Tema de colores elegido por el usuario. | `ThemeName` |
